# The landing page counts only the published catalogue

The figures on the landing page (courses, lessons, instructors, categories) count only Published courses and what belongs to them. A Draft or Archived course adds nothing, and a category counts only when at least one Published course is in it. The same rule picks the Featured Courses: the newest Published courses. A visitor can open everything the page counts, so the numbers never promise a course they cannot reach.

## Considered Options

- **Count every course and every category row**: rejected, because drafts and empty categories inflated the figures with things a visitor cannot open.
